AnoMark Training

      

        Training uses process datasets only. Check the datasets to include, or set a training file path to bypass the list (path wins).
        Dataset IDs in the text field and tags are combined with checkboxes: every filter must match (intersection).
      

      

        
        
        
      

      

      

        

          Training file (optional, overrides checkboxes/IDs below)
          
        

        

          Extra dataset ids (optional)
          
        

        

          Tags filter (optional)
          
        

      

      

        
        
        
      

      
The model is always stored under .ironsift-platform/anomark-trains/<id>/model.bin and can be downloaded from the table below. Training uses the in-process anomark library (no external binary).

Saved AnoMark trainings

      

        Each successful train is recorded in the platform database. A copy of the model and the exact
        training_input.jsonl (plus the request payload) is stored under
        .ironsift-platform/anomark-trains/<id>/.
      

      

        
      

      

    

  


  

    

      
Sigma (sigmazero)

      

        Evaluate Sigma rules on your process logs using the in-process
        sigmazero (sigma_zero) engine. Set the rules directory below. IronSift exports selected process datasets to JSONL (with process_name / command_line) and evaluates them in memory.
